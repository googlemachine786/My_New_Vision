# How to Run Real Ollama Tests

**Current Status**: Test script uses MOCK answers because Ollama server is not running.

---

## 🚀 Quick Start (3 Steps)

### Step 1: Install Ollama

**Windows:**
```powershell
# Download and install from:
https://ollama.ai/download/OllamaSetup.exe

# Or via winget:
winget install Ollama.Ollama
```

**Mac:**
```bash
brew install ollama
```

**Linux:**
```bash
curl -fsSL https://ollama.ai/install.sh | sh
```

---

### Step 2: Start Ollama Server

```bash
# Terminal 1: Start Ollama server
ollama serve
```

Leave this running in the background!

---

### Step 3: Pull Required Models

```bash
# Terminal 2: Pull embedding model
ollama pull nomic-embed-text

# Pull LLM model (choose one)
ollama pull llama3.2:3b      # Fast, good for testing
ollama pull llama3.2         # Latest version
ollama pull mistral:7b       # Better quality, slower
```

**Verify models are installed:**
```bash
ollama list
```

Expected output:
```
NAME                    ID              SIZE      MODIFIED
nomic-embed-text        ...             274 MB    ...
llama3.2:3b             ...             2.0 GB    ...
```

## 🔧 Troubleshooting

### "Cannot connect to Ollama"

```bash
# Check if Ollama is running
ollama list

# If not running, start it
ollama serve

# Check if port 11434 is in use
netstat -ano | findstr :11434
```

### "Model not found"

```bash
# Pull the missing model
ollama pull nomic-embed-text
ollama pull llama3.2:3b
```

### "Out of memory"

Use smaller models:
```bash
ollama pull qwen2.5:1.5b    # Very small, fast
ollama pull phi3:mini       # Small, good quality
```
